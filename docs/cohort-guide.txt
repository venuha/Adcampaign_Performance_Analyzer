AD CAMPAIGN PERFORMANCE ANALYZER — COHORT STARTER

What this project does
An original Streamlit prototype for Path B of your cohort brief. It uses pandas
for analysis and Plotly for charts. All four views share date, platform,
audience and campaign-goal filters. Campaign Details adds a name/ID search.
You can upload your own CSV and download the campaign summary.

Run locally (Python 3.12)
Open a terminal in this folder, then run:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    streamlit run app.py

Windows activation: .venv\Scripts\activate
Streamlit prints the local URL. Keep the terminal running while using the app.

Sample data
data/sample_campaign_data.csv contains 1,080 fictional daily records:
12 campaigns across Facebook, Instagram, Pinterest and Twitter, from
July 1 to September 28, 2026 (90 days). All money is USD.
Audiences: New customers, Returning customers, Lookalike audience.
Goals: Sales, Lead Generation, Brand Awareness.
This is synthetic training data, not data from real advertisers. Channel
differences are generated examples, not evidence about platform performance.
The sample includes paused days, zero conversions and losing campaigns.

CSV data dictionary
date: YYYY-MM-DD reporting date.
campaign_id: unique campaign identifier; one row per ID per day.
campaign_name: readable name, consistent within an ID.
platform: advertising channel, consistent within an ID.
audience: audience segment, consistent within an ID.
campaign_goal: campaign objective, consistent within an ID.
impressions: whole-number ad views.
clicks: whole-number tracked clicks, no greater than impressions.
conversions: whole-number tracked actions, no greater than clicks.
spend: daily ad cost in USD, non-negative.
revenue: daily attributed revenue in USD, non-negative.

Real uploads must use these exact column names and the same daily grain.
Use consistent attribution windows and a single currency. Extra columns are
ignored. This prototype rejects duplicate daily campaign records rather than
silently double-counting them. A campaign ID must keep the same metadata.
The conversion rule assumes at most one tracked action per click.

Metric definitions
CTR (%) = total clicks / total impressions * 100
CVR (%) = total conversions / total clicks * 100
CPC (USD) = total spend / total clicks
CPA (USD) = total spend / total conversions
ROAS (x) = total revenue / total spend
Ad ROI (%) = (total revenue - total spend) / total spend * 100

Ad ROI excludes product, fulfilment and operating costs. It is not net profit.
All rates are calculated from totals, never averaged across daily rows.
Zero denominators return N/A or chart gaps. Sample revenue is recorded only
for Sales campaigns. Leads and awareness actions have no assigned monetary
value, so revenue metrics should be compared within matching objectives.
